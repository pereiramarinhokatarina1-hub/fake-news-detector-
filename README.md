# 📌 Sobre o Projeto 

O **Fake News Detector Al** é um sistema web capaz de analisar noticias e identificar a probabilidade de serem falsas ou verdadeiras utilizando Inteligência Artificial Generativa.

Diferente de modelos simples de Machine Learning tradicionais, este projeto utiliza:

✅ IA contextual
✅ Análise semântica
✅ Interpretação textual
✅ Verificação de plausibilidade 
✅ Explicações automáticas

___
